# Behavioral Fraud Detection with Machine Learning

This project was developed during my Machine Learning internship at Innova IT Solutions.

The project focuses on unsupervised behavioral fraud detection using real-world financial transaction data. User-specific transaction patterns were modeled to identify deviations from normal behavior through statistical and machine learning-based anomaly detection techniques.

## Methods

- Isolation Forest
- One-Class SVM
- Z-Score
- Dynamic Thresholding
- Behavioral, temporal, and contextual feature engineering
- Rolling-window analysis
- Grid Search-based parameter optimization

## Technologies

Python, Scikit-learn, Pandas, NumPy, Seaborn
